# Obsidian 结构规则

默认根目录为用户指定 Vault 下的 `AI问题跟踪/`。不要写死具体电脑路径；如果用户已给出路径，按用户路径执行。

## 标准结构

```text
AI问题跟踪/
  AI问题清单.md
  AI问题解决记录列表.md
  AI问题解决记录/
    工作区与根层/
    AM记忆/
    CCOW协作/
    Skill与能力/
    AI问题记录系统/
    第三方吸收/
    其他/
  吸纳项目总结/
  AM进步点总结/
  _archive/
```

## 清单

`AI问题清单.md` 允许用户只分行写。AI 必须整理为：

```markdown
- [ ] 问题标题
```

解决并验证后才改为：

```markdown
- [x] 问题标题
```

不要要求用户自己写状态、编号、链接。

## 解决记录列表

`AI问题解决记录列表.md` 只给用户看索引：

```markdown
# AI问题解决记录列表

问题解决总数：3

## AI问题记录系统
- [[AI问题解决记录/AI问题记录系统/问题清单格式整理|问题清单格式整理]]
```

禁止：

- 表格。
- 模板。
- 说明文。
- 归档说明。
- `_archive/` 链接。

## 独立记录

问题记录放在：

```text
AI问题解决记录/<分类>/<问题标题>.md
```

吸纳总结放在：

```text
吸纳项目总结/<项目名>.md
```

AM 进步点总结放在：

```text
AM进步点总结/<日期或主题>.md
```

## 归档

不永久删除。撤回、废弃、误写文件移动到：

```text
_archive/<日期或原因>/
```

并写简短 `MANIFEST.md` 说明原路径和原因。
